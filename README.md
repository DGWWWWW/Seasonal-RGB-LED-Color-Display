# Seasonal LED String

This project uses a 50-pixel WS2811 RGB LED string to display various color combinations, patterns, and lighting effects. An Arduino UNO R4 WiFi controls the string.

The lighting modes can be selected using serial commands sent to the Arduino. The project can also connect to a home Wi-Fi router, allowing the lights to be controlled from a mobile phone or computer through a web browser.
